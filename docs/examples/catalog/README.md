# Example catalog entries

Four filled-in examples showing the shape defined in
[the catalog model](../../planning/02-catalog-model.md). These are illustrative drafts, not final
Buildour content. Phase 0 replaces them with real, reviewed content.

| File | Shows |
|------|-------|
| `system.finance.yaml` | A system with its questions and templates |
| `feature.invoicing.yaml` | A feature with options, free text and build fragments |
| `agent.invoice-reminders.yaml` | An agent with playbook, permissions, guardrails, and a `requires` dependency |
| `automation.overdue-escalation.yaml` | An automation with trigger, steps and failure handling |
